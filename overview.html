Blender UV Toolkit

Easeam 2 - faster seam marking and UV prep for Blender

Easeam 2 is a focused Blender add-on for artists who want faster UV seam marking, unwrap actions, and UV map management without leaving the 3D View workflow.

Use viewport previews, modal tools, one-shot selection tools, and UV utilities to handle common UV preparation jobs with fewer repetitive steps. Open the full documentation.

Easy seam marking Mark, clear, preview, and commit seams directly in Blender's viewport.
Modal operators Use hover previews for loops, flat regions, tubes, and custom paths.
One-shot tools Run selection-based operators when the source geometry is already selected.
UV utilities Refresh unwraps, convert UV islands into seams, and manage UV channels.

Where to find Easeam

  • 3D View > Sidebar > Easeam
  • 3D View > Mesh Edit Mode > Alt + S pie menu (coztumisable key pie)
  • Image Editor > Sidebar > Easeam (UVMap Manager only)

Requirements

  • Blender 5.1 or above
  • Best CPU for speed modal operation
